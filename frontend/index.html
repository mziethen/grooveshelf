Settings

This screen

Applies only to this browser. Choose Listening for your Pi display. The last selected album is remembered; opening it does not record a play. Direct record links still open that copy.

Discogs metadata

When disabled, no automatic provider requests are made for saved records. Expired details and covers are hidden unless you enable the option below. Your own corrections and personal fields are retained.

Older details are marked with their last check time. With automatic refresh disabled, cached details and covers stay available without contacting Discogs. This does not grant additional usage rights: displaying older snapshots may conflict with Discogs’ API terms, which require current data. Disabled by default.

When disabled, selecting a search result fills the draft directly. You can edit it before saving and choose a cover afterward. Records are saved only with Save record.

Inventory labels

Choose physical copies by LP number. Labels contain only the inventory number.

Print preview

Print at 100% / actual size on the selected paper. Disable headers and footers and set print margins to none; the document supplies its own margins. Test on plain paper before using label stock. You can choose Save as PDF in the print dialog.

Listening statistics

Recorded listening events per physical copy. Date and month boundaries use Europe/Berlin. Never played uses your entire history.

What should I play?

Least played uses the lowest lifetime count per copy. The 30-day selection includes never-played copies. Suggestions do not record a play.

    Sync with Discogs

    Review each change before applying it. LP numbers, NFC tags, listening history and local corrections stay in GrooveShelf. Missing copies are retained for review.

      Choose your Discogs release

      Use the number from the Discogs release URL, for example /release/12345. Album master IDs describe multiple pressings and cannot identify your copy.

      Remove missing Discogs link

      Your GrooveShelf record, LP number, NFC tag, photos and listening history will be retained. This removes its local collection association. The old Discogs instance remains remembered to prevent accidental reimport. No entry is deleted from Discogs.

      GrooveShelf checks Discogs again before removing the link. To match another copy or add it to Discogs, choose that action in a fresh sync preview.
