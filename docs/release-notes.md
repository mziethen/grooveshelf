# Discogs release notes

Record details, Discogs import previews and exact-release previews display available source notes in a collapsed disclosure. Choose **Discogs release notes** or **Reference release notes** to read them. Personal notes remain separate.

A selected release supplies notes for that pressing. An album master supplies notes from its reference release, which may differ from your copy. A source link points to the release that supplied the text when a valid URL is available. Missing or blank notes produce no empty section. Text is displayed literally, with line breaks preserved; Discogs formatting codes are not interpreted.

Source notes follow the same metadata freshness settings as credits and pressing details. Expired text is hidden unless showing older saved metadata is enabled. Updating the same record preserves the open disclosure and keyboard focus. Opening notes does not fetch additional metadata or create a listening event.

These are source release notes, which can describe packaging, recording or pressing details. GrooveShelf does not present them as an editorial album review. No additional provider or subscription is required.
